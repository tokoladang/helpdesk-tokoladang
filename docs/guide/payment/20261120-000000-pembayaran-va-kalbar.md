# Cara Pembayaran Virtual Account (VA) di Bank Kalbar

<PageDate />

## **Panduan Pembayaran Virtual Account (VA) Bank Kalbar Melalui CMS**

## 1. Login CMS Bank Kalbar
- Buka alamat resmi https://cms.bankkalbar.co.id 
- Masukkan ID Institusi.
- Masukkan ID Pengguna.
- Masukkan kata sandi.
- Klik **Masuk**
![Klik Masuk](/images/6.png)

## 2. Masuk ke Menu Virtual Account
- Login menggunakan User Maker, kemudian pilih:
- Transaksi → Virtual Account → Pendaftaran VA,akan masuk ke halaman
pembayaran Virtual Account (VA)

## 3. Melakukan Pembayaran VA
- Masukkan Nomor VA, klik **Selanjutnya.**
- Akan tampil informasi tagihan VA.
- Klik **bayar**
![Klik Masuk](/images/7.png)

## 4. Melakukan Otorisasi VA
- Login menggunakan User Releaser di alamat resmi https://cms.bankkalbar.co.id
- Pilih menu **Otorisasi** -> **Pembayaran**, akan masuk ke halaman otorisasi
pembayaran Virtual Account (VA)
- Pilih tagihan VA, jika satuan pilih tombol **Aksi** di kanan, klik **Disetujui**
- Pilih Disetujui.
- Masukkan OTP yang masuk ke Nomor HP dan Klik **Proses**
- Cek status dan riwayat pembayaran pada menu **Daftar Transaksi** -> **Pembayaran**

## 5. Memeriksa Informasi Pembayaran VA
- Cek status pembayaran pada Toko Ladang, jika sukses maka **Status Pesanan** akan
menjadi **Pembayaran diverifikasi**
