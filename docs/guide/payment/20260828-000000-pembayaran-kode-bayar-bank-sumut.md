# Panduan Pembayaran Kode Bayar Bank SUMUT

<PageDate />

**Tata cara pembayaran melalui TELLER Bank SUMUT**

1. Satuan Pendidikan datang ke Bank Sumut terdekat
2. Menyerahkan nomor Kode Bayar, KTP, Buku Tabungan/Bilyet Giro/Cek ke Teller
3. Teller mengkonfirmasi Pembayaran sesuai Tagihan ke Satuan Pendidikan
4. Bukti Pembayaran akan diserahkan Teller ke Satuan Pendidikan
5. Cek status tagihan transaksi pada aplikasi siplah Toko Ladang
<hr />

**Tata cara pembayaran melalui SUMUTNET Corporate**

**User: MAKER**

1. Login ke Aplikasi SUMUTNET Corporate dengan menginput Username, Password, dan Captcha
2. Pilih menu Pembayaran dan Sub Menu "Pembayaran Pendidikan"
3. Pilih instansi dengan mengklik Dropdown, Pilih Marketplace Toko Ladang
4. Input Nomor Kode Bayar, lalu klik "LANJUTKAN"
5. Periksa data Pembayaran, apabila data telah benar dan sesuai, user Maker melakukan klik "SIMPAN"

**User: CHECKER**

1. Menerima Email Notifikasi Pembayaran
2. Login ke layanan SUMUTNET Corporate dengan menginput Username, Password, dan Captcha
3. Pilih Menu Pembayaran, Approval Transaksi Pembayaran
4. Pilih transaksi yang akan di approve, kemudian klik tanda panah ➔ untuk melihat detail transaksi yang akan diapprove
5. Periksa data transaksi yang akan di approve, apabila telah benar dan sesuai, klik "SETUJU"
6. Akan muncul tampilan "Otorisasi Kode OTP" dikirim ke SMS atau Email.
7. Input kode OTP, kemudian klik "PROSES" untuk melanjutkan transaksi ke user Releaser

**User: RELEASER**

1. Menerima Email Notifikasi Pembayaran
2. Login ke layanan SUMUTNET Corporate dengan menginput Username, Password, dan Captcha
3. Pilih Menu Pembayaran, Release Transaksi Pembayaran
4. Pilih transaksi yang akan direlease, kemudian klik tanda ➔ untuk melihat detail transaksi yang akan direlease
5. Periksa data transaksi yang akan di release, apabila telah benar dan sesuai, klik "SETUJU"
6. Akan muncul tampilan "Otorisasi Kode OTP" dikirim ke SMS atau Email.
7. Input kode OTP, kemudian klik "PROSES" untuk merilis transaksi pembayaran SIPLah Tokoladang.
8. Apabila transaksi berhasil, akan muncul pop up: "Data berhasil di proses, keberhasilan transaksi dapat di lihat di menu monitoring"
