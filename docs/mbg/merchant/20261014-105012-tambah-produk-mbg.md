# Tambah Produk MBG

<PageDate />

**Tata Cara Menambah Produk MBG**

1. Login ke akun Toko di SIPLah Toko Ladang
2. Masuk ke halaman **Daftar Produk**, lalu klik tombol **Tambah Produk**
3. Setelah itu pilih kategori produk **Bahan Baku MBG (Makan Bergizi Gratis)**, Pilih **Produk**
   ![Kategori Produk](/images/mbg/kategori-produk.png)

> [!TIP]
> Kategori Bahan Baku MBG (Makan Bergizi Gratis), hanya aktif jika merchant terverifikasi via BGN URL Verified

4. Isi data form **Tambah Produk**
   ![Tambah Produk](/images/mbg/form-produk.png)
5. Centang Pernyataan, dan Klik Simpan
   ![Pernyataan](/images/mbg/pernyataan-save.png)
6. Produk langsung tayang.
